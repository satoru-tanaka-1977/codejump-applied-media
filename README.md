# Sneakers（メディアサイト）

CODEJUMP 応用編の「メディアサイト」課題として制作しているWebサイトです。

## 概要

HTML・CSS・jQueryを使用して、スニーカーメディアサイトを制作しています。

CODEJUMPの課題を通して、カルーセルスライダーの実装や、CSS Gridレイアウト、スクロール連動のフェードインアニメーションについて学習しています。

## 学習内容

- HTMLによるメディアサイト特有の構造設計（カルーセル・グリッド・お問い合わせフォーム）
- jQueryプラグイン（slick-carousel）によるカルーセルスライダーの実装
- CSS Grid（`grid-template-columns`、`repeat`、`auto-fit`、`minmax`）によるレスポンシブグリッド
- スクロール位置を検知したフェードインアニメーション
- ハンバーガーメニューの開閉処理
- jQueryによるページ内スムーススクロール
- レスポンシブ対応
- Git / GitHubによるバージョン管理

## 使用技術

- HTML5
- CSS3
- JavaScript（jQuery, slick-carousel）
- Git / GitHub
